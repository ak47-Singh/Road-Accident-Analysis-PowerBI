# Road-Accident-Analysis-PowerBI
Interactive Power BI dashboard for analyzing road accidents, casualties, severity, vehicle involvement and accident trends .

## 📌 Project Overview

This project focuses on the analysis of road accident data using Microsoft Power BI.
The objective is to transform raw accident data into meaningful insights through
data preprocessing, analysis and interactive visualization.

## 🎯 Objectives

- Analyze road accident data
- Identify accident trends and patterns
- Analyze casualty severity
- Study vehicle-wise accident involvement
- Compare accident trends across 2021 and 2022
- Analyze urban and rural accident distribution
- Analyze road type and lighting conditions
- Develop an interactive Power BI dashboard

## 📊 Dataset

The dataset used in this project was obtained from Kaggle.

The dataset contains information related to road accidents, casualties,
severity, vehicle types, road conditions, location and other relevant
accident-related attributes.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Kaggle Dataset
- Data Visualization

## 🔄 Data Preprocessing

The dataset was processed before visualization. Major preprocessing activities
included checking data quality, handling missing or inconsistent values,
removing unnecessary data, formatting columns and preparing fields for analysis.

## 📈 Dashboard

The dashboard provides an interactive view of:

- Total accidents
- Total casualties
- Fatal casualties
- Serious casualties
- Slight casualties
- Vehicle-wise casualties
- Monthly accident trends
- Urban vs Rural distribution
- Road type analysis
- Lighting condition analysis
- Geographical distribution

## 🔍 Key Insights

- Slight casualties represent the largest category.
- Cars account for the highest number of casualties among the analyzed vehicle types.
- Urban areas account for a higher proportion of casualties than rural areas.
- Single carriageways show the highest number of casualties among the analyzed road types.
- The dashboard allows comparison of accident trends between 2021 and 2022.
